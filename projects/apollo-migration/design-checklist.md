# Design checklist — Apollo Migration

Design projects only.

- [ ] Problem statement agreed
- [ ] Current state documented
- [ ] Options identified with trade-offs
- [ ] Non-functionals stated (availability, latency, scale, cost)
- [ ] Security / data handling reviewed
- [ ] Interfaces and contracts defined
- [ ] Dependencies and owners named
- [ ] Migration / rollout path
- [ ] Review with enterprise architecture
- [ ] Decisions recorded in decisions.md
